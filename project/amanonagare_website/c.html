自作スマホアプリ「Rainee」

自作スマホアプリ「Rainee」の仕組みを使って、/journal/dataにmarkdownデータを格納することで、Amano Journalの仕組みが成り立っています。

Raineeにはテキストボックスがあり、そこにスマホから軽々とテキストを入力することができます。

まだあまり高度な制御をできるようにはしていませんが、将来的にはまた改善を加えていきたいです。

RaineeではgithubのPATを利用することで、リモートリポジトリにmarkdownデータをpushすることができます。markdownデータは、日付ごとにファイル名を付けて格納されます。

そのため、PCを使用せずにAmano Journalに日誌を記録することができます。スマホからでも簡単に日誌を記録することができるのは、非常に便利です。

まだ写真を添付することはできませんが、将来的には写真を添付することもできるようにしたいです。

Raineeにできることはあくまでmarkdownデータをリモートリポジトリにpushすることだけです。markdownデータをhtmlに変換して表示するのは、Amano Journalの仕組みです。下記を参照してください。

markdownをjournalのhtmlに表示する仕組み

実は、html自体に書かれていることは非常に少なく、journal-listというidの付けられたコンテナとトップに戻るリンク、そして/build/js/journal.tsを起動するscriptタグの3つしかありません。

先述した通り、markdownデータが/journal/dataに格納されており、/build/js/journal.tsがそれを読み込み、htmlに変換してjournal-listコンテナに挿入する仕組みになっています。

/build/js/journal.tsは、1つの関数定義、2つのclass定義、1つの変数定義、2つの関数呼び出しで構成されています。

構成要素の定義

■ SimpleDate class

  • メンバ変数: public y: number, public m: number, public d: number（内部的にそれぞれ年/月/日を表す）
  • メンバ関数:
    • constructor(y: number, m: number, d: number)
    • public next(): 日付を1日進める。valid関数で日付を確認し、正しくない場合は繰り上げ処理を行う。
    • public prev(): 日付を1日戻す。valid関数で日付を確認し、正しくない場合は繰り下げ処理を行う。
    • public clone(): SimpleDate: インスタンスを複製して返す。
    • public to_int(): number: 元年1月1日からの経過日数を整数で返す。

■ Rainee class

  • メンバ変数: public date: SimpleDate
  • メンバ関数:
    • public constructor(date: SimpleDate): 引数にSimpleDateインスタンスを受け取り生成する。
    • public async fetch(): Promise<void>: 内部変数にmarkdown文字列を格納する（失敗時は何も格納しない）。
    • public append_to(parent_elem: HTMLElement): markdownをhtmlに変換し、引数で渡された要素の子要素として挿入する（未格納時は処理を行わない）。

■ 関数・変数定義

  • function today(): SimpleDate: 今日の日付のSimpleDateインスタンスを返す。
  • journal_list_elem: HTMLElement: journal-listというidを持つコンテナを取得して格納する。
関数の呼び出し

最初の関数呼び出しでは、marked.jsを用いてmarkdown内の改行をbrタグに変換する設定を実行します。marked.parse()でHTML変換を行いますが、その前にmarked.use({breaks: true})を実行しておくことで、改行を適切に反映させます。

もう一つの関数呼び出しは最下部のmain関数で、ここで全体の処理が一括して実行されます。

main関数の処理フロー

main関数には非同期処理のためにasyncが付与されており、前半が変数の初期化、後半がデータ取得と描画処理に分かれています。

まず、開始日となる2026年9月1日のインスタンス（変数d）と、today()から取得した今日の日付（変数t）を生成します。同時に、非同期処理を格納するpromis_vec（Promise<void>[]）とインスタンスを保持するrainee_vecを空配列として用意し、t.to_int() - d.to_int()により対象期間の日数nを算出します。

次にjournal_list_elemのnullチェックを行ってHTMLElement型を確定させた後、0からnまでのループ処理に入ります。ループ内では日付dを渡してRaineeインスタンスを生成し、rainee.fetch()をpromise_vecに、インスタンス自体をrainee_vecに登録した上で、d.next()により日付を1日進めます。このループはPromiseの登録のみを行うため一瞬で完了します。

ループ終了後、Promise.all(promis_vec)で全件のデータ取得を並列待機します。完了後はrainee_vecを内部のdateをもとに降順ソートし、全要素のappend_to(journal_list_elem)を実行してjournal-listコンテナへ順次挿入します。

これでHTMLへの変換および描画処理は完了です。

現状でも動作しますが、HTML変換時の拡張機能の追加や、記事データが増加した際の通信量肥大化といった課題が残されています。

将来的には4カ月単位でのデータ分割を行い、ページネーション機能を導入することを検討しています。
